Cara Melihat Password WiFi yang Tersimpan di Laptop Windows 11 Tanpa Aplikasi Tambahan

2026-10-16T10:38:00+07:00 | TUTORIAL

Jendela Wireless Network Properties di Windows 11, password WiFi yang tersimpan dapat dilihat dengan mencentang opsi Show characters pada Network security key.

PULNEW - Lupa password WiFi padahal laptop sudah terhubung otomatis menjadi masalah umum, terutama saat ingin menghubungkan HP atau laptop lain. Kabar baiknya, Windows 11 menyimpan semua password tersebut dan bisa dilihat kembali hanya dalam 15 detik tanpa perlu aplikasi tambahan. Cukup dengan satu perintah rahasia http://ncpa.cpl, password yang berbentuk titik-titik bisa ditampilkan secara utuh.

Masalah ini terjadi karena sistem Windows secara default menyembunyikan Network Security Key demi alasan keamanan. Banyak pengguna akhirnya melakukan reset router hanya karena tidak tahu cara melihatnya kembali. Padahal fitur Wireless Network Properties sudah tersedia sejak Windows 7 dan masih berfungsi sempurna di Windows 11. Metode ini jauh lebih aman dibandingkan menggunakan aplikasi pembobol WiFi yang berisiko membawa malware.

1. Langkah Cepat Menampilkan Password WiFi Melalui http://ncpa.cpl

Metode ini adalah yang paling cepat dan stabil dibandingkan lewat menu Settings yang terkadang loading lama. PULNEW sudah menguji langsung di laptop dengan Windows 11 24H2.

1. Buka Kotak Dialog Run. Tekan tombol Windows + R secara bersamaan di keyboard. Kotak kecil Run akan muncul di pojok kiri bawah layar.

2. Ketik Perintah http://ncpa.cpl. Pada kolom Open, ketik persis ncpa.cpl lalu tekan Enter atau klik OK. Perintah ini akan langsung membuka jendela Network Connections yang berisi semua adapter jaringan.

3. Masuk ke Status WiFi yang Aktif. Di dalam jendela tersebut akan terlihat dua adapter, yaitu Ethernet dan WiFi. Klik kanan pada adapter WiFi yang sedang terhubung, biasanya namanya Wi-Fi atau nama SSID, kemudian pilih Status. Jika opsi Status tidak muncul, klik dua kali langsung pada ikon WiFi tersebut.

4. Buka Wireless Properties. Pada jendela Wi-Fi Status yang menampilkan durasi koneksi dan kecepatan, klik tombol Wireless Properties di bagian tengah.

5. Lihat Password di Tab Security. Akan muncul jendela baru dengan dua tab. Pindah ke tab Security. Di sana akan terlihat kolom Network security key yang berisi titik-titik. Centang kotak Show characters, maka password asli akan langsung terlihat.

Catatan penting: Langkah ini hanya bisa menampilkan password WiFi yang sedang atau pernah terhubung di laptop tersebut. Jika belum pernah terhubung sama sekali, kolom akan kosong.

2. Solusi Jika Opsi Wireless Properties Tidak Muncul atau Akses Ditolak

Pada beberapa kasus, terutama laptop kantor atau laptop dengan akun terbatas, metode di atas bisa gagal. Berikut penanganan yang sering berhasil.

1. Jalankan Dengan Hak Administrator. Saat mengetik http://ncpa.cpl di Run, sistem akan menampilkan notifikasi This task will be created with administrative privileges. Klik Yes. Tanpa hak admin, tombol Wireless Properties akan berwarna abu-abu dan tidak bisa diklik.

2. Alternatif Lewat Control Panel Jika Run Gagal. Jika shortcut Windows + R tidak berfungsi, buka Control Panel > Network and Internet > Network and Sharing Center > Change adapter settings. Hasilnya sama dengan perintah http://ncpa.cpl.

3. Adapter WiFi Tidak Muncul. Jika hanya muncul Ethernet dan tidak ada WiFi, berarti driver WiFi belum terinstall atau WiFi dalam keadaan disabled. Klik kanan > Enable pada adapter WiFi, atau update driver melalui Device Manager.

4. Password Tetap Tidak Terlihat. Ini biasanya terjadi pada jaringan kantor yang menggunakan Security Type WPA2-Enterprise. Pada tipe Enterprise, password tidak disimpan dalam bentuk teks melainkan sertifikat, sehingga kolom Network security key memang sengaja dikosongkan oleh administrator.

Trik tambahan yang jarang diketahui, setelah password terlihat, segera salin dan simpan di password manager seperti 1Password atau di aplikasi Notes yang terkunci. Jangan simpan dalam file notepad biasa di desktop karena mudah dibaca orang lain.

3. Cara Alternatif Melihat Semua Password WiFi yang Pernah Tersimpan

Kelemahan metode http://ncpa.cpl adalah hanya bisa melihat satu WiFi yang sedang aktif. Jika ingin melihat daftar semua WiFi yang pernah terhubung sebelumnya, gunakan Command Prompt.

1. Buka CMD Sebagai Admin. Ketik CMD di pencarian Start, kemudian pilih Run as administrator.

2. Ketik Perintah Daftar Profil. Masukkan perintah netsh wlan show profiles lalu Enter. Semua nama WiFi yang pernah tersimpan akan muncul.

3. Tampilkan Password Spesifik. Untuk melihat password salah satunya, ketik netsh wlan show profile name="NAMA_WIFI" key=clear Ganti NAMA_WIFI dengan nama SSID yang ada di daftar, misalnya Airtel_wifi_xxxx. Password akan terlihat di bagian Key Content.

Metode CMD ini sangat berguna ketika pengguna ingin melihat password WiFi rumah yang sudah lama tidak dikunjungi tetapi pernah terhubung di laptop tersebut. Kombinasikan kedua metode ini untuk hasil maksimal.

Dengan memahami cara kerja Network Connections dan Wireless Security, pengguna tidak perlu lagi panik saat diminta memasukkan password WiFi yang terlupa. Metode http://ncpa.cpl terbukti menjadi yang paling praktis karena tidak memerlukan koneksi internet tambahan dan bekerja secara offline. Panduan yang disusun oleh PULNEW ini sudah dipraktikkan langsung dan bisa diterapkan di hampir semua laptop Windows 10 dan Windows 11 tanpa terkecuali.
