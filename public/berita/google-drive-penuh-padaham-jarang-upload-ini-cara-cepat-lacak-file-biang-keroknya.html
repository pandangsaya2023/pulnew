Google Drive Penuh Padahal Jarang Upload? Ini Cara Cepat Lacak File Biang Keroknya

2026-09-26T07:18:00+07:00 | TEKNOLOGI

PULNEW - JAKARTA - Pengguna akun Google gratis yang mendapati notifikasi penyimpanan penuh padahal merasa jarang mengunggah file kini bisa melakukan pengecekan mandiri dengan langkah yang sangat praktis. Kapasitas Google Drive yang terbatas hanya 15 GB dan harus berbagi dengan Gmail serta Google Photos membuat tumpukan data tak penting sering kali menjadi penyebab utama memori sesak.

Kondisi tersebut kerap menimbulkan kebingungan, terutama ketika pengguna sudah menghapus beberapa dokumen namun indikator penyimpanan tetap berwarna merah. Ternyata, penyebab penuhnya ruang tidak selalu berasal dari dokumen yang baru saja diunggah, melainkan dari file berukuran jumbo yang tersembunyi dan terlupakan di dalam akun. File tersebut bisa berupa video mentah, backup WhatsApp, file proyek, hingga arsip ZIP yang ukurannya mencapai gigabyte.

Google sebenarnya telah menyediakan fitur khusus untuk mengatasi persoalan ini. Pengguna tidak perlu lagi membuka folder satu per satu secara manual yang tentu memakan waktu lama. Cukup dengan memanfaatkan menu penyimpanan, sistem akan menampilkan seluruh file yang ada beserta informasi ukurannya secara rinci. Dari sana pengguna bisa langsung mengetahui file mana yang paling banyak memakan kuota.

Mekanisme kerjanya tergolong sederhana. Di dalam dasbor Google Drive versi desktop maupun aplikasi mobile, terdapat panel bernama Storage atau Penyimpanan yang berada di sisi kiri bawah layar. Menu tersebut tidak hanya menampilkan diagram penggunaan ruang, tetapi juga merangkum total pemakaian dari tiga layanan utama, yakni Drive, Gmail, dan Photos. Dengan begitu pengguna bisa melihat apakah yang penuh itu Drive-nya atau justru Photos dan email-nya.

Setelah masuk ke menu tersebut, pengguna akan disuguhkan daftar lengkap seluruh file yang tersimpan di akunnya. Untuk memudahkan pencarian biang kerok, pengguna dapat memanfaatkan fitur filter pengurutan. Dengan mengklik ikon panah pada kolom Penyimpanan, daftar akan otomatis berubah dari yang terbesar ke yang terkecil. File dengan ukuran paling besar akan langsung naik ke urutan paling atas, sehingga tidak perlu lagi menebak-nebak.

Langkah detailnya adalah buka aplikasi atau situs Google Drive, kemudian pilih opsi Penyimpanan. Di halaman tersebut akan terlihat sisa kuota dan total penggunaan. Pada bagian bawahnya terdapat tabel file. Klik opsi Penyimpanan yang ada ikon panahnya, maka sistem akan menyortir file secara otomatis. Dari posisi teratas itulah pengguna bisa mulai menyeleksi mana yang masih relevan untuk dipertahankan dan mana yang sudah bisa dibuang.

Penyebab Umum Storage Google Tetap Penuh Meski Sudah Hapus File

Banyak pengguna mengeluhkan bahwa mereka sudah menghapus banyak file namun status penyimpanan Google Drive tetap penuh. Fenomena ini ternyata memiliki penjelasan teknis yang sering terlewatkan. File yang dihapus dari Drive tidak langsung hilang permanen, melainkan akan dipindahkan terlebih dahulu ke folder Sampah atau Trash dan tetap dihitung sebagai pemakaian kuota selama 30 hari sebelum terhapus otomatis.

Selain faktor sampah yang belum dikosongkan, penyebab lain yang kerap tidak disadari adalah cadangan aplikasi pihak ketiga. Backup chat WhatsApp yang diatur harian ke Google Drive bisa menyedot ruang hingga puluhan gigabyte tanpa disadari. Demikian pula dengan file di Google Photos yang disetel dengan kualitas original, serta lampiran email di Gmail yang memiliki file besar seperti video presentasi atau file desain.

Untuk mengosongkan ruang secara efektif, pengguna disarankan untuk melakukan pembersihan menyeluruh di tiga tempat sekaligus. Pertama, kosongkan folder sampah di Google Drive secara manual setelah menghapus file besar. Kedua, cek folder Spam dan Trash di Gmail karena lampiran besar juga memakan kuota yang sama. Ketiga, buka Google Photos dan hapus video berdurasi panjang yang tidak penting atau ubah pengaturan penyimpanan dari Original ke Storage Saver agar lebih hemat ruang.

Tips tambahan yang bisa diterapkan adalah memanfaatkan fitur pencarian dengan perintah khusus. Di kolom pencarian Drive, ketik larger:500M untuk menampilkan semua file di atas 500 megabyte, atau owner:me untuk melihat file milik pribadi saja. Trik ini sangat membantu bagi pengguna yang memiliki ribuan file dan ingin menyaring file jumbo dengan cepat tanpa harus menggulir daftar yang sangat panjang.

Strategi Mengelola File Besar Agar Google Drive Tetap Lega

Mengelola ruang penyimpanan gratis memang membutuhkan strategi agar tidak cepat penuh kembali dalam waktu singkat. Setelah berhasil menemukan dan menghapus file terbesar, pengguna perlu membiasakan diri melakukan audit rutin. Setidaknya satu bulan sekali, luangkan waktu untuk memeriksa menu Storage dan melihat pertumbuhan file apa yang paling signifikan dalam 30 hari terakhir.

Alternatif lain jika file tersebut masih dibutuhkan namun tidak ingin membebani kuota adalah memindahkannya ke layanan penyimpanan lain atau ke hard disk eksternal. Untuk file portofolio kerja atau file video, pengguna bisa memanfaatkan platform lain yang memang dirancang untuk itu, sehingga Drive bisa difokuskan hanya untuk dokumen penting dan file kolaborasi harian. Pengguna juga bisa mengompres file video sebelum mengunggahnya agar ukurannya jauh lebih kecil.

Google juga memberikan opsi berlangganan Google One bagi pengguna yang memang membutuhkan ruang lebih besar. Namun sebelum memutuskan untuk berlangganan, langkah pembersihan file besar ini adalah solusi gratis yang paling masuk akal. Dengan menghapus satu file video 4K berdurasi 1 jam saja, pengguna bisa langsung mendapatkan kembali ruang hingga 15-20 GB, yang setara dengan mengosongkan ribuan file dokumen kecil.

Penting juga untuk memperhatikan file yang dibagikan oleh orang lain. File yang ada di Shared with me tidak memakan kuota pribadi, kecuali jika pengguna membuat salinannya atau menambahkannya ke My Drive. Oleh karena itu, hindari menduplikasi file film atau file ISO yang dibagikan di grup, karena tindakan tersebut akan langsung menyedot kuota akun pribadi.

Keberadaan fitur pengurutan berdasarkan ukuran ini pada dasarnya menjadi jalan pintas yang sangat membantu produktivitas. Pengguna tidak perlu lagi menginstal aplikasi tambahan atau menggunakan layanan pihak ketiga yang berisiko terhadap keamanan data. Semua sudah disediakan secara native oleh Google dan bisa diakses kapan saja baik lewat laptop maupun ponsel.

Menurut pantauan PULNEW, persoalan Google Drive penuh di kalangan pengguna Indonesia saat ini bukan lagi sekadar soal kebiasaan upload, melainkan soal kurangnya literasi digital dalam mengelola sampah digital. Banyak pengguna yang tidak tahu bahwa sistem kuota 15 GB itu terintegrasi, sehingga ketika Gmail penuh karena lampiran, Drive ikut terdampak dan tidak bisa menerima file baru.

Fenomena storage penuh yang tidak kunjung lega meski sudah hapus file juga menunjukkan bahwa edukasi tentang folder Trash masih sangat minim. Padahal, mengosongkan Trash adalah kunci utama agar ruang yang sudah dihapus benar-benar kembali. Tanpa langkah itu, upaya menghapus file besar menjadi sia-sia karena sistem masih menghitungnya sebagai bagian dari pemakaian.

Ke depan, kebiasaan audit file bulanan seharusnya menjadi standar baru bagi pengguna akun gratis. Dengan memanfaatkan filter ukuran file dan perintah pencarian lanjutan, pengguna bisa menghemat biaya langganan dan menjaga performa akun Google tetap optimal tanpa harus terus-menerus dihantui notifikasi penyimpanan hampir habis.
