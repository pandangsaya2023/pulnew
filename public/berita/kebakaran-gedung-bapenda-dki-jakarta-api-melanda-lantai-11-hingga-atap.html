Gedung Bapenda DKI Jakarta Terbakar Hebat, Kobaran Api Hanguskan Lantai 11 hingga Atap

2026-08-07T19:04:00+07:00 | NASIONAL

PULNEW.COM - Musibah kebakaran berskala besar melanda fasilitas Gedung Badan Pendapatan Daerah (Bapenda) DKI Jakarta yang bertempat di Jalan Abdul Muis pada Jumat malam, 7 Agustus 2026.

Kronologi Awal Kemunculan Api

Berdasarkan laporan yang dihimpun di lapangan, amukan si jago merah pertama kali terdeteksi sekitar pukul 21.30 WIB. Titik awal kemunculan api diketahui berasal dari area lantai 11 bangunan tersebut. Tanpa memakan waktu lama, kobaran api dengan cepat merambat naik hingga mengoyak bagian atap gedung, sehingga memicu kebakaran yang kian meluas dan membesar.

Upaya Pemadaman dan Dampak Musibah

Memasuki hari Sabtu, 8 Agustus 2026, sekitar pukul 00.10 WIB, jajaran petugas pemadam kebakaran terlihat masih terus berjibaku di lokasi untuk mengendalikan kobaran yang membakar sisi luar gedung serta menjalar ke lantai bagian bawah. Berbagai upaya penanggulangan secara intensif terus dikerahkan guna mencegah pergerakan api makin meluas. Insiden ini dipastikan menimbulkan kerusakan fisik yang sangat signifikan pada infrastruktur gedung dan berpotensi mengganggu aktivitas di area sekitarnya. Pemerintah setempat bersama tim penyelamat kini terus berkoordinasi intensif untuk menangani dampak musibah serta menentukan langkah-langkah pemulihan pascakebakaran.
