Kebakaran Gedung Bapenda DKI Jakarta: Api Melanda Lantai 11 hingga Atap

2026-08-07T19:04:00+07:00 | NASIONAL

Sebuah kejadian kebakaran yang cukup parah terjadi di Jakarta pada Jumat, 7 Agustus 2026, ketika Gedung Badan Pendapatan Daerah (Bapenda) DKI Jakarta di Jalan Abdul Muis dilanda api.

Kebakaran Mulai Muncul

Menurut informasi yang diterima, api pertama kali dilaporkan muncul sekitar pukul 21.30 WIB dari lantai 11 gedung. Api kemudian dengan cepat merambat ke bagian atap gedung, menyebabkan kebakaran yang semakin meluas.

Hingga Sabtu, 8 Agustus 2026, pukul 00.10 WIB, petugas masih berusaha mengendalikan api yang membakar sisi gedung dan menjalar ke lantai bagian bawah. Upaya pemadaman api terus dilakukan untuk mencegah kebakaran semakin meluas.

Dampak dan Langkah Selanjutnya

Kebakaran ini tentunya menyebabkan kerusakan yang signifikan pada gedung dan berpotensi menyebabkan gangguan pada aktivitas di sekitarnya. Pemerintah setempat dan tim penyelamat terus bekerja sama untuk mengatasi dampak kebakaran dan menentukan langkah-langkah selanjutnya untuk memulihkan kerusakan yang telah terjadi.
