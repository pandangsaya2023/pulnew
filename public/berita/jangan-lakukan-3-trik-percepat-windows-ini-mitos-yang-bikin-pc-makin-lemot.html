2026-10-21T16:00:00+07:00 | SAINS & EDUKASI

Trik viral mengatur Number of Processors di msconfig System Configuration adalah mitos lama. Windows secara default sudah memakai semua core, mencentangnya justru bisa membatasi performa.

PULNEW - Lagi scroll TikTok atau Reels, kamu pasti pernah lihat video "3 Simple Speed Up PC Tips" dengan cara mengetik msconfig, aktifkan semua processor, lalu hapus file prefetch. Komentar isinya bilang work, padahal setelah dicoba PC malah tetap lemot atau bahkan booting jadi lebih lama. Video itu viral karena terlihat meyakinkan, tapi dua dari tiga triknya adalah mitos lama yang sudah dibantah Microsoft sejak era Windows 7.

Kenapa trik menyesatkan seperti ini terus laku? Karena Windows yang mulai melambat memang bikin frustasi. File sampah menumpuk, startup penuh aplikasi tidak penting, dan sistem butuh waktu untuk memuat cache. Solusi instan seperti mencentang opsi di System Configuration terlihat seperti tombol turbo rahasia. PULNEW sudah menguji langsung ketiga langkah yang ada di video tersebut di laptop Windows 11, dan hasilnya tidak seperti yang dijanjikan.

1. Bongkar Mitos MSConfig Number of Processors dan Folder Prefetch

Ini bagian yang paling sering disalahpahami kreator.

Trik MSConfig -> Number of Processors: Di video disuruh buka Run (Windows + R), ketik msconfig, masuk ke tab Boot > Advanced options, lalu centang Number of processors dan pilih angka tertinggi. Logikanya biar semua core dipakai saat nyala. Faktanya: Windows 11 secara default SUDAH memakai semua core yang tersedia untuk proses boot. Opsi ini sebenarnya adalah fitur debugging untuk developer yang ingin MEMBATASI core, misalnya untuk tes aplikasi di CPU dual-core. Kalau kamu centang manual, kamu justru berisiko salah setting. Contoh nyata, laptop kamu 8 core tapi kamu set 4 karena iseng, performa malah kepotong setengah. Solusi yang benar adalah biarkan opsi ini tidak tercentang (unchecked).

Trik Hapus Folder Prefetch: Langkah kedua yang disuruh adalah ketik prefetch di Run, lalu hapus semua file .pf di C:\Windows\prefetch. Faktanya: Folder Prefetch itu bukan sampah. Itu adalah catatan pintar Windows agar aplikasi favorit kamu seperti Chrome, Photoshop, atau game bisa dibuka lebih cepat. Windows menyimpan jejak loading agar next time buka jadi ngebut. Kalau kamu hapus total, efeknya justru sebaliknya, semua aplikasi akan loading ulang dari nol dan terasa lebih lemot selama 2-3 hari sampai cache terbentuk lagi. Windows juga akan membuat file itu lagi secara otomatis, jadi aksinya sia-sia.

2. Satu-Satunya Trik yang Valid: Aktifkan Storage Sense dengan Setting yang Tepat

Di Windows 11, fitur ini ada di Settings > System > Storage > Storage Sense. Ini memang resmi dari Microsoft untuk bersih-bersih otomatis. Tapi jangan cuma di-On-kan saja, banyak orang lupa atur jadwalnya.

Ini settingan rekomendasi PULNEW yang sudah kami pakai untuk laptop kerja sehari-hari:

● Buka Settings > System > Storage > Storage Sense > Aktifkan toggle ke On. ● Di bagian Configure cleanup schedules, atur Run Storage Sense: Every Week. Jangan During low disk space saja, karena kalau sudah low baru jalan itu sudah terlambat. ● Delete files in my recycle bin if they have been there for over: 14 days. Jangan set 1 hari, kadang kita masih butuh file yang tidak sengaja terhapus. ● Delete files in my Downloads folder if they haven't been opened for: 30 days. Ini kunci. Folder Downloads adalah sumber sampah terbesar. ● Klik Run Storage Sense now di bawah untuk eksekusi pertama.

Dari pengujian, dengan setting ini laptop kami berhasil merebut kembali 2,29 GB ruang kosong tanpa perlu install aplikasi pembersih tambahan seperti CCleaner. Efek ke kecepatan terasa karena SSD punya ruang lega untuk caching.

3. Cara yang Benar-Benar Bikin Windows Ngebut (Yang Jarang Dibahas)

Kalau tujuan kamu adalah boot lebih cepat dan aplikasi tidak lemot, tinggalkan msconfig dan prefetch. Lakukan tiga hal ini:

A. Matikan Startup yang Tidak Penting Lewat Task Manager, Bukan MSConfig: Tekan Ctrl + Shift + Esc > buka tab Startup Apps. Disable semua yang Status-nya High Impact tapi tidak kamu pakai tiap hari, contoh: Spotify, Adobe Creative Cloud, OneDrive jika tidak dipakai. Ini memangkas waktu boot hingga 40% di laptop kami.

B. Ganti HDD ke SSD dan Cek Storage Health: Secepat apapun kamu utak-atik software, kalau masih pakai Hard Disk mekanik, Windows 11 akan tetap lemot. Investasi SSD SATA 512GB sekarang sudah di bawah 400 ribu. Setelah ganti, cek Health dengan buka Command Prompt dan ketik wmic diskdrive get status.

C. Gunakan Disk Cleanup Versi Lama untuk File Sistem: Selain Storage Sense, ketik cleanmgr di Run, pilih Drive C:, lalu klik Clean up system files. Centang Windows Update Cleanup dan Previous Windows installations. Seringkali file ini memakan 10-20 GB setelah update besar dan tidak dibersihkan oleh Storage Sense.
