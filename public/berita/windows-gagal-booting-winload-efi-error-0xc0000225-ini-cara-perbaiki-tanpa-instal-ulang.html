Windows Gagal Booting http://winload.efi Error 0xc0000225? Ini Cara Perbaiki Tanpa Instal Ulang

2026-10-15T20:45:00+07:00 | TUTORIAL

PULNEW - Layar hitam dengan logo Windows muter terus tulisannya "Getting ready" lalu tiba-tiba pindah ke "Diagnosing your PC" dan berakhir di layar biru Recovery dengan tulisan File: \windows\system32\winload.efi Error code: 0xc0000225. Panik? Wajar. Error ini bikin laptop Dell, ASUS, Lenovo kamu nggak bisa masuk Windows sama sekali, padahal data skripsi atau kerjaan ada di dalam.

Jangan buru-buru instal ulang, http://winload.efi bukan berarti harddisk rusak, tapi bootloader Windows yang korup. Penyebab paling umum: mati listrik mendadak saat update Windows, kamu dual-boot Linux, clone SSD, atau partisi EFI nggak sengaja ke-format. Windows 10 dan 11 yang pakai UEFI memang sensitif di bagian ini. File http://winload.efi itu jembatan antara firmware UEFI dan sistem Windows. Kalau jembatannya hilang, Windows nggak tahu harus load dari mana.

1. Masuk ke Windows Recovery Environment dan Buka Command Prompt

Kamu nggak butuh flashdisk instalasi kalau Windows masih bisa memanggil Recovery otomatis. Caranya:

  • Paksa matikan laptop 3x berturut-turut. Nyalakan > saat logo Windows muncul tekan tahan tombol power sampai mati. Ulangi 3x, nanti otomatis masuk layar "Choose an option".
  • Kalau punya flashdisk installer Windows, colok lalu boot dari flashdisk, pilih Repair your computer.
  • Di layar biru pilih Troubleshoot > Advanced options > Command Prompt.
  • Nanti akan terbuka CMD dengan path X:\windows\system32>. Pilih akun Administrator dan masukkan password kalau diminta.

Catatan penting: pastikan kamu cabut semua harddisk eksternal dan USB lain biar CMD nggak salah deteksi drive Windows.

2. Eksekusi Perintah Bootrec Untuk Perbaiki MBR dan Boot Record

Ini inti perbaikannya. Banyak tutorial cuma kasih satu perintah, padahal harus berurutan. Ketik satu per satu, tekan Enter tiap baris:

Langkah A - Perbaiki Master Boot Record:

  • bootrec /fixmbr - Perintah ini menulis ulang MBR yang kompatibel dengan Windows. Tunggu sampai muncul "The operation completed successfully".
  • bootrec /fixboot - Menulis ulang boot sector baru di partisi sistem. Di sistem UEFI modern sering muncul "Access is denied". Itu normal, jangan panik. Lanjut saja ke langkah berikutnya.

Langkah B - Scan dan Rebuild Data Boot:

  • bootrec /scanos - Perintah ini akan scan semua disk untuk mencari instalasi Windows. Prosesnya agak lama, biarkan sampai selesai. Kadang hasilnya "Total identified Windows installations: 0" di kasus tertentu, tetap lanjut.
  • bootrec /rebuildbcd - Ini yang paling krusial. Dia akan scan lagi dan kalau menemukan Windows kamu, akan muncul pertanyaan "Add installation to boot list?". Ketik Y lalu Enter.

Kalau semua perintah sudah sukses, ketik exit lalu pilih Continue - Exit and continue to Windows 10. Biasanya laptop langsung booting normal.

3. Kalau Masih Access is Denied, Pakai Jurus BCDBOOT Untuk UEFI

Di laptop keluaran 2018 ke atas yang sudah pakai UEFI, bootrec /fixboot hampir pasti gagal. Solusi yang work adalah rebuild file EFI secara manual pakai bcdboot.

Begini trik yang dipakai saat fixboot ditolak:

  • Masih di Command Prompt yang sama, cek dulu drive Windows kamu ada di huruf apa. Biasanya di Recovery, C: jadi D:. Ketik diskpart > list vol. Cari volume dengan label EFI atau FAT32 ukuran 100-300MB, dan volume Windows yang besar. Catat hurufnya, misal Windows di D: dan EFI di C:. Ketik exit untuk keluar dari diskpart.
  • Jalankan perintah: bcdboot D:\Windows /s C: /f UEFI - Sesuaikan D: dengan drive Windows kamu, dan C: dengan partisi EFI. Perintah ini menyalin ulang semua file boot termasuk http://winload.efi yang hilang tadi.
  • Kalau partisi EFI kamu belum punya huruf, beri huruf dulu lewat diskpart: select vol X (X adalah volume EFI) > assign letter=S: > exit > lalu jalankan bcdboot D:\Windows /s S: /f UEFI
  • Setelah sukses, ketik exit dan restart.

Pencegahan biar nggak kejadian lagi: jangan matikan paksa laptop saat update Windows lagi berjalan, selalu eject dual-boot Linux dengan benar, dan aktifkan System Restore Point minimal seminggu sekali. Kalau kamu sering clone SSD, pastikan pakai software yang support UEFI clone seperti Macrium Reflect bukan clone mentah.

Error http://winload.efi 0xc0000225 memang kelihatan serem karena layar biru Recovery, tapi bukan vonis harddisk mati. Dengan urutan bootrec yang benar plus bcdboot untuk UEFI, kamu bisa selamatkan Windows tanpa instal ulang dan data tetap aman. Saya sendiri sudah buktikan di beberapa unit Dell dan ASUS, hasilnya balik ke desktop normal dan bisa login lagi. Kalau sudah normal, langsung backup data penting ke Google Drive. PULNEW rekomendasikan cek kesehatan SSD pakai CrystalDiskInfo setelah kejadian ini untuk pastikan nggak ada bad sector yang memicu corrupt file boot.
